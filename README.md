# Shift Tracking System

A web app where employees clock in and out and admins manage employees, working schedules and attendance corrections. Clock times always come from an external Europe/Zurich time service.

## Prerequisites

- Docker
- OpenSSL (included with macOS and Linux)

## Quick Start

Run the commands one at a time from the project folder.

1. Create the local `.env` file with new random secrets:

```bash
sh scripts/setup-env.sh
```

2. Start the application (the first start takes a minute or two):

```bash
docker compose up --build
```

3. Open http://localhost:3000

## Demo & Login

**Admin**

- Email: `admin@example.com`
- Password: generated by `scripts/setup-env.sh`, printed in the terminal and saved in `.env` (`SEED_ADMIN_EMAIL` and `SEED_ADMIN_PASSWORD`). Every reviewer generates their own, so no password needs to be sent by email.

**Employee**

1. Sign in as the admin and open **Employees**.
2. Click **New link** on an employee (or **Add employee** to create one) and copy the one-time invitation link.
3. Open the link in a private browser window and set a password.
4. Sign in as the employee with their email and that password.

**Sample data:** a new, empty database includes four example employees (Anna Meier, Marco Rossi, Lea Keller, Noah Weber) with their working weeks and attendance records for the last two weeks: normal days, a missing day, extra hours, a corrected clock-out and a deleted shift. The example shifts are shown as manual entries, because real clock-in and clock-out times only come from the time service.

## Tests

Backend (runs in Docker):

```bash
docker compose run --rm backend-tests
```

Frontend (needs Node.js):

```bash
cd frontend && npm install && npm test
```

## Stopping the Application

```bash
docker compose down
```
