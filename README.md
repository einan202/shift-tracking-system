# Shift Tracking System

A web app where employees clock in and out and admins manage employees, working schedules and attendance corrections. Clock times always come from an external Europe/Zurich time service.

## Prerequisites

- Docker
- OpenSSL (included with macOS and Linux)

## Quick Start

Run the commands one at a time from the project folder.

1. Create the local `.env` file with new random secrets:

```bash
sh scripts/setup-env.sh
```

2. Start the application (the first start takes a minute or two):

```bash
docker compose up --build
```

3. Open http://localhost:3000

## Admin Login

- Email: `admin@example.com`
- Password: a unique random password, generated by the setup script and printed in the terminal when you run it.
- The same credentials are saved in the local `.env` file (`SEED_ADMIN_EMAIL` and `SEED_ADMIN_PASSWORD`).
- Every reviewer generates their own credentials, so no password needs to be sent by email.

After signing in, the admin can add an employee and send them the invitation link, which lets the employee choose their own password. A new, empty database also contains four example employees with a few example shifts (shown as manual entries).

## Tests

Backend (runs in Docker):

```bash
docker compose run --rm backend-tests
```

Frontend (needs Node.js):

```bash
cd frontend && npm install && npm test
```

## Stopping the Application

```bash
docker compose down
```
